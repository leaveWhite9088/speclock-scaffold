# 3 分钟演示录屏执行脚本（demo-script）

本清单供录制第 11 课提交视频（时长控制在 3 分钟内，等待环节可快进，建议配简要字幕）时直接按序复制执行，确保与根目录 `report.md` 中的命令与路径一一对应。

---

## 第一段：开场一句话介绍（约 15 秒）

展示仓库根目录 `report.md` 与 `README.md` 架构图，口播说明项目定位：多模型编码代理调度系统，统一由守护进程管理执行者连接池，按锁定版本规格实现「需求审批 → 编码实现 → 独立测试验收」闭环。

---

## 第二段：依次执行报告中的验证与压测命令（约 75 秒）

在仓库根目录终端依次运行以下四条命令并展示绿屏退出结果：

```powershell
# 1. 安全门禁（密钥扫描 0 命中 + 依赖漏洞受控 + 越权/注入反例 + 观测告警触发）
npm run check:security

# 2. 质量总门禁（分层单向依赖 + 操作表 + 数据布局 + 并发队列 + 全套单元契约）
npm run check

# 3. 崩溃预写日志对账验证（事务与崩溃一致性）
npm --prefix packages/agentd run test:interrupted

# 4. 20 并发性能压测（展示回执检索缓存优化后 >2000 QPS、P95 ~15ms）
npm run bench
```

---

## 第三段：核心业务功能与观测界面走查（约 90 秒）

1. 启动网关与看板（或已通过 `docker compose up -d --wait` 启动）：
   ```powershell
   npm run backend
   npm run web
   ```
2. 浏览器打开看板：
   - **建项目与执行者**：选择项目根目录，基于内置角色模板创建「需求」「后端开发」「测试工程师」执行者（可混合不同 CLI）。
   - **下发需求与异步执行**：向调度器输入一句业务需求，展示任务立即返回 `jobId` 并在后台流式更新进度、思考过程与工具调用（不阻塞当前对话）。
   - **回执、观测指标与隔离验证**：访问 `http://127.0.0.1:8787/api/health`（展示 `ok: true` 与 `gitSha`）及 `http://127.0.0.1:8787/api/metrics?format=prom`（展示各执行者调用量计数、耗时 P95 与三段式告警状态）。
