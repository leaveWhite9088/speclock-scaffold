# SpecLock 规格库

这个项目的业务规格放在 SpecLock 里，它是规格的唯一依据：大业务 → 小业务 → 模块，每个模块有背景、规则（R-1…）、验收条件（AC-1…）和 API。
你已经接好了它的 MCP 工具（名字是 `speclock`），身份和权限由脚手架配好，**不需要也不应该**自己找 key、换 key、创建 key，也不要打开或读取任何 `.key` 文件。

- 开始工作前先调一次 `whoami`，确认你的角色和下面写的一致；不一致就停下来，在回复里说明，不要继续。
- 规格怎么改、谁来批准，都由 SpecLock 和调度器管：**你不能批准审核单**，也不要替用户说“同意”。
- 不要碰 SpecLock 的数据库或数据目录；不清楚的行为看工具说明，再不行就在回复里问。
- 你和别的执行者不直接说话。要告诉别人什么，写在回复里，调度器会转达。
